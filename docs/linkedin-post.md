🚀 Just shipped my new project: **AI Codebase Assistant**

Ever wished you could just *ask* a codebase a question?

I built a full-stack RAG app that:

✅ Ingests any GitHub repo or ZIP (10+ languages)
✅ Chunks code semantically — file paths, function names, line numbers
✅ Embeds chunks into @Pinecone (1536-d vectors, cosine)
✅ Answers questions via @OpenAI / @Anthropic with LangChain
✅ Streams responses in real time & cites the exact file + lines

Stack: Next.js 15 · TypeScript · Tailwind · Express · LangChain ·
Pinecone · deployed on @Vercel + @Render
